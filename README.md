# carousel-like-shashlik

Приватный навык Codex для создания содержательных Instagram-каруселей «как с шашлыками».

## Скачать

Откройте файл `carousel-like-shashlik-skill.zip` в репозитории и нажмите **Download raw file**.

## Установить

1. Распакуйте архив.
2. Поместите папку `carousel-like-shashlik` в каталог личных навыков Codex:
   - macOS/Linux: `~/.codex/skills/carousel-like-shashlik`
   - Windows: `%USERPROFILE%\.codex\skills\carousel-like-shashlik`
3. Начните новый чат Codex.
4. Для явного запуска укажите `$carousel-like-shashlik` в запросе.

Основная инструкция `SKILL.md` доступна в корне репозитория. Полный комплект с `references/`, `assets/` и `agents/` находится в архиве `carousel-like-shashlik-skill.zip`.
